# Digital Queue System Documentation

Welcome to the documentation for the Digital Queue System.

This project is a monorepo containing a Go backend for authentication and a placeholder for a React frontend. The system uses Docker for containerization, Kong as an API gateway, and PostgreSQL for data storage.

-   [**Architecture Overview**](./architecture.md): A high-level look at the system's components and how they interact.
-   [**Backend API Reference**](./backend-api.md): Detailed documentation for the backend authentication service API.
