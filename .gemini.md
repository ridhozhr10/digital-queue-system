# Gemini Project Configuration

This file helps Gemini understand the project structure, common commands, and your preferences.

## Project Overview

- **Name:** Digital Queue System
- **Description:** A monorepo for a digital queue system with a Go backend and a React frontend. The system uses Docker for containerization, Kong as an API gateway, and PostgreSQL for data storage.
- **Primary Language:** Go

## Common Commands

You can use the `run` command with these aliases. For example: `run test`.

- **test:** `go test ./...`
- **build:** `go build ./...`
- **docker-up:** `make compose-up`
- **docker-down:** `make compose-down`
- **docker-logs:** `make compose-logs`
- **docker-status:** `make compose-ps`
- **dbmate:** `npx dbmate`

## File & Directory Exclusions

Please ignore the following files and directories when performing searches or modifications:

- `third_party/`
- `*.sum`
- `*.png`
